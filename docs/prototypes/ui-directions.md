## 0. 这次要解决的三件事

| 问题 | 现状 | 目标 |
|---|---|---|
| 左下角「引擎未连接」 | 已定位：`tauri dev` 的 devUrl 是 `http://127.0.0.1:1430`，引擎 CORS 只放行 `tauri.localhost` | 已修：CORS 放行任意回环 origin；壳需重启 |
| 深色壳 + 浅色页面 | 壳 `#080A0D` 暖黑，工作台 `#f5f6f8` 冷白，同屏出现 | 整窗只有一种模式 |
| Windows 蓝色标题条 | 系统标题栏 + 壳顶栏两层，蓝色很跳 | 无边框窗口 + 自绘 44px 标题栏 |

三套方案都包含后两项；差别在**用几种模式、谁来承担阅读面**。

---

## 1. 方案 A · Signal Desk（一体化暗色）

**一句话**：一套暗色 token 贯穿外壳与所有页面，琥珀只留给「正在发生的事」。

- 外壳、工作台、文件、人物、设置全部暗色；`rooms.css` 的深色信号语言升级为全局语言。
- 分栏用 1px 发丝线，不用卡片投影；信息密度高，像一台常驻的信号台。
- 强调色规则：琥珀 = 直播/进行中/可操作；玉绿 = 采集正常；红 = 异常；蓝只做链接。
- 自绘标题栏与顶栏合并为 44px，右侧是窗口控制按钮。

**适合**：夜间长时间盯播、希望产品有强识别度、认同 docs/23 里「深色信号语言作为产品识别」。
**代价**：`index.css`（695 行）和文件/人物/阅读页都要做暗色 token 覆盖，约 1.5–2 天；图表、时间轴、证据高亮需要逐项校对比度。
**风险**：长时间读逐字稿的舒适度不如浅色；白天办公场景偏重。

---

## 2. 方案 B · Studio / Paper（双主题，按视图整窗切换）

**一句话**：监听是暗色工作室，工作台/资料是暖纸阅读面；**整窗一起换，不再深壳套浅页**。

- `收听 / 实时字幕` → Studio：沿用现在的暗色信号语言。
- `工作台 / 文件 / 人物 / 设置` → Paper：暖白纸面（`#F3F0E9`），强调色改为深琥珀（`#A76A22`），不是现在的冷蓝。
- 顶栏、活动栏、对象列表、状态栏跟随当前视图换肤，切换时 140ms 过渡；iframe 通过 `?theme=paper|studio` 接收主题。
- 同一套 token 命名、同一套圆角/间距/字号，两种模式只是取值不同。

**适合**：白天读稿、晚上盯播都要兼顾；想尽量保留现有浅色工作台的投入。
**代价**：约 1 天；主要是壳的双主题 + 页面暖纸重着色 + iframe 主题桥。
**风险**：两套主题会随时间漂移，需要把 token 收敛到一个文件并加视觉回归截图。

---

## 3. 方案 C · Quiet Graphite（中性石墨，卡片分栏）

**一句话**：中性灰 + 墨绿强调，浮起的圆角面板，跟随系统明暗；最接近当代桌面工具。

- 外壳改为中性石墨，不再是暖黑；品牌色从琥珀改为墨绿，琥珀只保留给「录制中」。
- 分栏从「无缝发丝线」改为「8px 间隙 + 12px 圆角卡片」，活动栏也变成一张独立卡片。
- 收听画布是一块深色媒体卡（像播放器），外围仍是浅色；这是**有意的对比**，不是深壳套浅页。
- 支持 `prefers-color-scheme`，`?mode=dark` 可看深色版（[截图](shots/ui-c-dark.png)）。

**适合**：想要「现代、克制、像 Linear/Notion」的观感；团队里有人更习惯浅色。
**代价**：约 1.5 天；新 token + 卡片布局 + 页面去蓝。
**风险**：识别度最弱，容易像通用工具；墨绿与「直播」的联想不如琥珀直接。

---

## 4. 共同要做的事（与选型无关）

1. **无边框窗口**：`decorations: false` + 自绘标题栏（拖拽区、双击最大化、最小化/最大化/关闭走 Tauri IPC），彻底去掉 Windows 蓝色标题条。
2. **主题桥**：壳在 iframe URL 上加 `theme=`，`embed.js` 读参数写 `document.documentElement.dataset.theme`；页面 CSS 只认 token。
3. **嵌入页统一**：隐藏页面自己的顶栏（已有），把页面内的「面板标题栏」高度、圆角、字号对齐壳的画框。
4. **状态栏语义**：引擎未连接时给出可操作信息（端口、诊断入口），不要只写「重试中」。

## 5. 怎么评审

```bash
"C:/Program Files/Google/Chrome/Application/chrome.exe" "C:/path/to/livenotes/docs/prototypes/ui-directions.html?d=a"
```

- `?d=a|b|c` 切方案；`?view=listen|workbench` 切画布；`?d=c&mode=dark` 看 C 的深色。
- 页面底部有切换条；左侧「收听 / 工作台」也能切。
- 建议重点看：**工作台**（浅色冲突最明显）和**收听**（深色是否过重）两屏。

---

## 6. 建议

**首选 B**：它用最小改动消掉「同屏深浅混搭」，同时保留工作台已有的浅色阅读面；等产品身份更确定后，再决定是否收敛到 A 的一套暗色。

如果更看重「一台常驻信号台」的识别度，选 A；如果更看重「现代、通用、跟随系统」，选 C。
