# 配置大模型（多档案）

顶栏 **⚙ 设置** 打开抽屉。第一次用也可以直接在表单里填完点「测试连接」，通过即自动保存。

## 连接档案：一个档案 = 一套地址 + 模型 + Key

档案是**列表**，每行显示名称 + 模型 + 域名，当前使用的那行左侧有蓝条：

| 操作 | 说明 |
|---|---|
| 点一行 | 切换成这一份；**总结和自动标题立刻改用这份** |
| ✎ | 改名（弹窗输入，不影响地址/Key） |
| ⧉ | 复制这份（含 Key），改改就是另一个账号 / 另一个中转 |
| ✕ | 删除这份配置；**可以删到一份不剩**，删空后显示「还没有配置」，点「＋ 新建」重新开始 |
| ＋ 新建 | 清空表单，填完点「保存」或「测试连接」就多一份 |

删除只删配置本身，已录的场次、逐字稿、总结都不受影响。

档案存在 `data/settings.json`，形如：

```json
{
  "version": 2,
  "active": "p3f9c1",
  "profiles": {
    "p3f9c1": {"name":"中转 · api.example.com","provider":"custom",
               "base":"https://api.example.com/v1","model":"example-model",
               "key":"sk-...","temperature":0.3}
  }
}
```

旧的单配置文件会自动迁移成一份档案，不会丢。

## 字段

| 字段 | 说明 |
|---|---|
| 服务商模板 | DeepSeek / OpenAI / Moonshot / 智谱 / 通义 / Groq / Ollama / 自定义 |
| 接口地址 | OpenAI 兼容协议，一般以 `/v1` 结尾 |
| 模型 | 手填，或「拉取列表」从 `GET {base}/models` 拉回来点选 |
| API Key | 留空表示不修改这份档案已有的 Key；**不会回传给浏览器**，只显示末四位 |
| 温度 | 0~1，越低越稳定；总结建议 0.2~0.4 |

「测试连接」用**表单里当前的值**（不用先保存）发一次最小请求（只发 `ping`，不带 `max_tokens`，
显式 `stream:false`），通过后自动保存；失败也会保存，方便改天重试。

**「逐个试」**：中转站的模型列表常常一半是死的。点它会把列表里每个模型各打一次最小请求
（最多 12 个、每个 12 秒超时），能用的标绿 ✓、不能用的划掉 ✕，悬停看具体错误。
全部失败基本可以断定是中转站上游/余额问题，不是本地配置。

## 环境变量（可选）

`LIVENOTES_LLM_BASE / _KEY / _MODEL` 仍是兜底值：一份档案都没配时才会用到。

并发上限、重试退避、单场/每日 token 预算、重复点击去重、任务失败重试，见
[`docs/10-llm-task-scheduler.md`](10-llm-task-scheduler.md)。

## 安全

Key 明文保存在本机文件里（权限 0600），和放浏览器 localStorage 是同一等级的本机风险——
本服务只监听 `127.0.0.1`。目录要是会进 git，把 `data/settings.json` 加进 `.gitignore`。

## 改完模型，旧总结会变吗

不会。已保存的总结是快照，记录了当时用的引擎（如 `llm(deepseek-chat)`）；
想让旧场次用新模型，重新点一次「生成总结」。
